# Hotel Management System

A simple hotel management system with functionalities for room reservation, customer management, service listing, and checkout. The project is implemented in both C++ and Python.

## Features:
- **Room Reservation System**: Allows customers to book rooms.
- **Available Services**: Displays a list of services available at the hotel.
- **Balance Calculation**: Calculates the total balance based on room price and services selected.
- **Checkout**: Manages the checkout process for customers.
- **Exit System**: Closes the system and exits after completing all tasks.

## Technologies Used:
- **C++** for the main logic and system handling
- **Python** for a version with simpler and more flexible features

## How to Run:
1. Clone the repository:
 ```bash
  git clone https://github.com/huda-alq/Hotel-Management-System.git
```

2. Navigate to the project folder: cd Hotel-Management-System

3. For each version:
C++:
 a. Compile the C++ file:
 g++ HotelManagementSystem_c++.cpp -o hotel
 b. Run the compiled program:
./hotel

Python:
Run the Python script:
python HotelManagementSystem_python.py
